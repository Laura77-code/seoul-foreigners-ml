# PROJECT_CONTRACT.md

# Seoul Foreigners ML — Shared Project Contract

This document defines the common methodological rules that every team member must follow.

The purpose is to ensure that notebooks `02`, `03`, and `04` analyze different research dimensions while using the **same dataset, targets, train/test split, preprocessing principles, and evaluation rules**.

---

## 1. Project Main Objective

Analyze and predict overall life satisfaction among foreign residents in Seoul using demographic, socioeconomic, linguistic, health, and social-integration factors from the 2025 Seoul Survey.

## 5. Shared Data Loading Pattern

Every modeling notebook should begin by loading the same master dataset and the same respondent IDs.

```python
from pathlib import Path
import pandas as pd

PROJECT_ROOT = Path.cwd().resolve()

if PROJECT_ROOT.name == "notebooks":
    PROJECT_ROOT = PROJECT_ROOT.parent

DATA_DIR = PROJECT_ROOT / "data" / "processed"

df = pd.read_csv(
    DATA_DIR / "seoul_foreigners_modeling_master.csv"
)

train_ids = pd.read_csv(
    DATA_DIR / "train_ids.csv"
)["ID"]

test_ids = pd.read_csv(
    DATA_DIR / "test_ids.csv"
)["ID"]

train_df = df[df["ID"].isin(train_ids)].copy()
test_df = df[df["ID"].isin(test_ids)].copy()

assert len(train_df) == 2000
assert len(test_df) == 500
assert set(train_df["ID"]).isdisjoint(set(test_df["ID"]))
```

## 6. Shared Preprocessing Rules

### Nominal features

Examples:

- nationality
- visa/status category
- housing category
- district
- binary demographic categories

Default preprocessing:

```text
Most-frequent imputation
+
One-Hot Encoding
```

### Ordinal features

Examples:

- Korean proficiency scales
- ordered satisfaction/difficulty scales

Default preprocessing:

```text
Median imputation
+
StandardScaler when the model is scale-sensitive
```

### Continuous / ratio features

Examples:

- age
- months in Korea
- income / monetary variables
- rent / deposit variables

Default preprocessing:

```text
Median imputation
+
optional log transformation
+
StandardScaler for scale-sensitive models
```

### Scaling

Default:

```text
StandardScaler
```

Alternative experiment:

```text
MinMaxScaler
```

Scaling must be fitted on training data only.

---

## 7. Missing Values

Do not use a global:

```python
df.fillna(0)
```

Missing values may represent:

- information not collected;
- a conditional question;
- a non-applicable question;
- a legitimate missing response.

Use the preprocessing pipeline for imputation.

For high-missingness survey variables, verify questionnaire logic before including them.

---

## 8. Outliers

Notebook 01 identified possible IQR outliers.

These observations must **not** be automatically deleted.

Examples such as high income, long residence duration, or older respondents may be valid observations.

Outlier removal requires an explicit domain or data-quality justification.

---

## 9. Derived Features

Shared derived features include:

```text
age
months_in_korea
korean_proficiency_mean
korean_proficiency_10
```

Avoid redundant feature representations.

Examples:

```text
Use age instead of SQ3
Use months_in_korea instead of SQ4_1 + SQ4_2
```

For Korean proficiency, choose one of:

```text
Q1_1 + Q1_2 + Q1_3 + Q1_4
```

or

```text
korean_proficiency_10
```

unless the experiment explicitly compares both representations.

---

## 10. Target Leakage Rules

Never use these as predictors:

```text
ID
Q11
high_satisfaction
```

The following variables were flagged as target-proximal and should not be included automatically in the core predictive models:

```text
Q4_1–Q4_7
Q10_1–Q10_5
Q14
```

If a role-specific analysis needs one of these variables, it must be clearly labeled as an **extended / explanatory analysis**, not part of the core predictive model.

---

## 11. Heavy-Tailed Features

Notebook 01 identified strong positive skewness in:

```text
months_in_korea
SQ6_1
SQ6_2
```

Available transformed candidates:

```text
months_in_korea_log1p
SQ6_1_log1p
SQ6_2_log1p
```

Later notebooks may compare raw vs. transformed representations.

Do not use both automatically.

---

## 12. Classification Evaluation

Because the classes are not perfectly balanced, accuracy alone is not sufficient.

Every classification experiment should report:

```text
Accuracy
Precision
Recall
F1
ROC-AUC
Confusion Matrix
```

Use the same positive class:

```text
1 = high satisfaction
```

---

## 13. Regression Evaluation

Every regression experiment should report:

```text
MAE
RMSE
R²
```

---

## 14. Cross-Validation

Model selection and hyperparameter tuning must be performed using the **training set only**.

Recommended:

```text
5-fold cross-validation
```

The test set should be used only for final evaluation.

---

## 15. PCA and Dimensionality Reduction

PCA is not part of the shared preprocessing.

It may later be tested in Notebook 05 as an optional experiment.

The main reason is that this project also wants to interpret which social and socioeconomic variables matter.

---

Use:

RANDOM_STATE = 42

whenever the algorithm supports a random state.

All changes must be reproducible from code.
