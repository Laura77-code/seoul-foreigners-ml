# Seoul Foreigners ML Project

Machine Learning final project using the 2025 Seoul Survey foreign residents dataset.

## Main objective
Analyze and predict life satisfaction among foreign residents in Seoul using demographic,
socioeconomic, linguistic, health, and social-integration factors.

## Project structure

- `data/raw/` — original dataset files. Do not modify them.
- `data/processed/` — cleaned/preprocessed datasets generated by notebooks/scripts.
- `notebooks/` — exploratory analysis, preprocessing, and modeling notebooks.
- `src/` — reusable Python functions.
- `figures/` — exported plots for the report/presentation.
- `results/` — model metrics, tables, and experiment outputs.
- `report/` — final report materials.
- `docs/` — variable dictionary, decisions, and team notes.

## First step

Place the original 2025 Seoul Survey foreign-resident dataset inside:

`data/raw/`

Recommended filename:

`seoul_survey_foreigners_2025.xlsx`

Do not commit the raw dataset to GitHub unless its license/terms explicitly allow redistribution.
