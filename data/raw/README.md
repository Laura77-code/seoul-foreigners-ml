# Local survey data (not tracked)

Download the 2025 Seoul Survey dataset from the Seoul Metropolitan Government:
https://data.seoul.go.kr/dataList/OA-15564/F/1/datasetView.do

Place the foreign-resident workbook at `data/raw/seoul_survey_foreigners_2025.xlsx`. Its official Korean `코드북` worksheet defines all survey codes. This repository never ships respondent-level data or re-licenses survey material. Run notebooks 00 and 01 after obtaining the file locally.
